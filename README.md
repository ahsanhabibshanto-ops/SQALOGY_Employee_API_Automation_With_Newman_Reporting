## SQALOGY API AUTOMATION PROJECT WITH NEWMAN REPORTING

## About this project
This project focuses on **Employee API Automation Testing**, covering key operations such as Create, Get, Delete, Search and Updating Employee records using different parameters. Automated test cases were developed to validate API functionality and data accuracy, and **Newman** was used to execute the Postman collection and generate comprehensive test reports.

## Pre-requisite
- Node js

## Tools & Technology
- Postman
- Visual Studio Code

## API Documentation [Employee API Documentation](https://documenter.getpostman.com/view/57047093/2sBYHUTfQd)

## How to run this project
**Clone Project**
```bash
https://github.com/ahsanhabibshanto-ops/SQALOGY_Employee_API_Automation_With_Newman_Reporting.git
```
**Hit The Command**
``` bash
npm init -y
```
``` bash
npm i newman
```
``` bash
npx newman run [collection] -e ["environment"]
```
``` bash
npm i newman-reporter-htmlextra
```
``` bash
node ./report.js
```
