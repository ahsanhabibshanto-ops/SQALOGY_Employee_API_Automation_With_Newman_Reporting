## SQALOGY API AUTOMATION PROJECT WITH NEWMAN REPORTING

## About this project
This is an employee API automation project. This project is facilitated to Create employee, Get employee, Update employee list with different parameter. Here we have created automation and generated a Newman report.

## Pre-requisite
- Node js

## Tools & Technology
- Postman
- Visual Studio Code

## API Documentation [Employee API Documentation](https://documenter.getpostman.com/view/57047093/2sBYHUTfQd)

## How to run this project
**Clone Project**
```bash
https://github.com/ahsanhabibshanto-ops/EmployeeApiAutomationWithNewmanReporting.git
```
**Hit The Command**
``` bash
npm init -y
```
``` bash
npm i newman
```
``` bash
npx newman run [collection] -e ["environment"]
```
``` bash
npm i newman-reporter-htmlextra
```
``` bash
node ./report.js
```
